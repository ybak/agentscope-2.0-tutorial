# AI CLI:编程助手团队实战

> 状态:规划中

## 定位

AI 编程 CLI(Claude Code 等)在团队开发流程中的标准化使用:从个人效率工具到团队工作规约——配置与模型接入、项目记忆与约定注入、技能与子代理、权限与成本治理。本书是**团队效能向的实战册**,与 `mcp` 书平级:CLI 既是 MCP 的消费端(工具接入),也是团队 AI 工作流的入口。

> 占位初稿:具体覆盖哪些 CLI、各讲多深,立项时确定。

## 目标读者

- 开发(全员):日常开发工作流的标准化
- 平台/运维:企业环境接入(代理、私有模型)、权限与成本治理
- 与平台缺口地图的对应:缺口地图暂未单列本域,属**开发效能**补充项(团队工作流标准化),不计入平台技术缺口

## 章节规划(初稿)

| 章节 | 内容一句话 |
|------|-----------|
| 第 1 章 初识 AI 编程 CLI | 为什么团队要标准化 AI CLI 的使用,主流工具概览 |
| 第 2 章 安装与配置 | 模型接入、代理与企业网络环境、多环境配置管理 |
| 第 3 章 日常开发工作流 | 代码理解、修改、调试与重构的实操模式 |
| 第 4 章 项目记忆与约定注入 | 仓库级 CLAUDE.md / 规约文件,让 CLI 遵守团队代码风格 |
| 第 5 章 技能与子代理 | 自定义命令、hook、并行任务与工作流自动化 |
| 第 6 章 团队协作与安全治理 | 权限模式、沙箱隔离、成本监控与用量规范 |
| 第 7 章 与平台工程结合 | CI 中的 CLI 用法、通过 MCP 接入内部工具(→ mcp 书) |

> 章节规划为初稿,启动时细化。
