# RagFlow:从入门到进阶

> 状态:规划中

## 定位

RAG 引擎实战,从搭建知识库到生产级检索调优。本书以 RagFlow 为主线,覆盖从部署、知识库构建到检索调优的完整链路,并把**知识库运营**(切片治理、更新流程、质量巡检)作为一等公民——RAG 系统上线只是开始,长期质量靠运营。

## 目标读者

- 后端工程师 / 平台工程师:搭建与运维 RagFlow,为智能体平台提供知识库能力
- 知识库运营:负责切片治理、文档更新流程与质量巡检

## 章节规划(初稿)

| 章节 | 内容一句话 |
|------|-----------|
| 第 1 章 初识 RagFlow | RagFlow 是什么、能解决什么问题,与直接用向量库自建 RAG 的取舍 |
| 第 2 章 部署与配置 | 单机与生产环境部署、模型与 Embedding 通道配置 |
| 第 3 章 知识库构建 | 文档接入、解析、切片与向量化全流程 |
| 第 4 章 切片策略治理 | 切片模板选择、分块参数调优与切片质量标准 |
| 第 5 章 检索与对话 | 混合检索、重排与对话编排,检索质量定位方法 |
| 第 6 章 RAG 评估 | 检索命中率与回答质量的评估指标与数据集 |
| 第 7 章 生产运维 | 多副本、监控、备份与容量规划 |
| 第 8 章 知识库运营流程 | 文档更新流程、质量巡检与多租户知识库治理 |

> 章节规划为初稿,启动时细化。
