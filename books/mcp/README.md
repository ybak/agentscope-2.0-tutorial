# MCP:跨框架工具接入协议

> 状态:规划中

## 定位

Model Context Protocol,统一工具接入的跨框架标准。本书是一本**薄专题册**:讲清 MCP 协议本身——核心概念、工具/资源/提示的建模方式与跨框架对接,让同一套工具能力可以被不同编排框架复用,避免为每个框架重复封装。

## 目标读者

- 全角色:协议本身与框架无关,后端工程师为主要实现者,平台与运维关注部署与安全,测试与运营了解工具目录与能力边界即可

## 章节规划(初稿)

| 章节 | 内容一句话 |
|------|-----------|
| 第 1 章 初识 MCP | Model Context Protocol 要解决什么问题,与函数调用/自定义插件的对比 |

| 第 5 章 跨框架客户端接入 | AgentScope 等编排框架对接 MCP 的方式与注意事项 |
| 第 6 章 部署与安全 | 传输方式(stdio/HTTP)、鉴权与生产环境部署要点 |
