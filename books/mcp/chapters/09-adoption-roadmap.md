# 第 9 章 企业落地路线图

> 给决策者与平台团队的章:从"技术可行"到"组织落地"。

## 本章节级大纲

- 落地四阶段:**Pilot**(3-5 个高频场景工具,验证价值)→ **域 Server 试点**(单业务域完整方法)→ **网关+检索规模化**(多域聚合)→ **常态治理**(目录、变更、评估例行化)
- 组织分工:中台团队 vs 业务团队各自拥有什么(Server 归属、描述质量责任、审批流)
- 成本模型:token 成本、维护成本、重复建设成本的量级估算
- 与现有微服务治理体系的融合:网关、限流、审计、发布流程怎么接 MCP
- 反模式清单:全量暴露接口、一个工具一个接口、描述交给自动生成不精修、无版本策略、跳过 Pilot 直接铺开
- 章节收尾:一页纸的落地决策树

## 写作备注

- 素材:团队真实落地过程(优先沉淀);行业公开案例(AWS / Cloudflare / GitHub MCP Server 等的规模化叙事)
- 核对清单:引用的外部案例数据标注出处与日期;成本数字尽量给估算框架而非绝对值
