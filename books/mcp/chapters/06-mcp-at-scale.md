# 第 6 章 规模化:业务中台的 MCP 化

> **全书最重的一章**,网上教程几乎空白的地带:数千接口的中台怎么暴露。核心命题:**不是暴露数千个工具**。

## 本章节级大纲

- 工具过载问题:LLM 工具选择准确率随工具数下降;上下文预算与成本
- **接口 ≠ 工具**:任务粒度聚合——「创建售后单」聚合校验+风控+创建三接口;面向 Agent 的任务语义,不是面向系统的资源语义
- **自动化生成管线**:OpenAPI/Swagger → MCP 工具的转换器(schema 与描述自动生成初稿、人工精修描述);团队 Swagger 资产的复用路径
- **域拆分 + Gateway**:按业务域拆 Server(订单/物流/商品/售后);MCP Gateway 聚合层;header 路由在 2026-07-28 下的应用
- **工具检索与动态发现**:search + load 模式、tools/list 分页、按角色/租户挂载子集
- 目录治理:命名规范全域推行、工具目录(哪个域有哪些工具)、变更管理(工具变更不破坏存量 Agent)
- 贯穿案例完整走一遍:售后域 20 接口 → 6 个任务级工具 → Gateway → 多框架消费
