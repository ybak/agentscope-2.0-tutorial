# 第 5 章 工具接入实战

> 全书分量最重的两章之一:把"能调通"提升到"模型爱用、生产可靠"。

## 本章节级大纲

- 参数 schema 设计:类型选择、必填/可选、约束表达、嵌套结构控制
- 命名与描述质量:LLM 靠描述选工具——描述质量 = 可用性;命名规范(`domain.action`)在此立规,第 6 章规模化沿用
- 错误处理:可重试 vs 不可重试、错误信息对模型友好(能据以自纠)、超时语义
- 大结果处理:分页、截断策略、资源引用(tools ↔ resources 配合)
- 幂等性:哪些工具必须幂等、重试风暴的防护
- 工具的评估起步:参数命中率、失败率如何观测(埋点细节 → langfuse 书)
- 贯穿案例:售后域前 3 个工具的完整建模过程(从 OpenAPI 片段到成品工具)
