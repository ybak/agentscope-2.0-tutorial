title: 第一篇 起步
source: 新写
---

当你第一次接触 AgentScope，面对 ReActAgent（实现“推理 → 调用工具 → 观察结果”循环的基础 Agent）、HarnessAgent（在此循环之上叠加工程能力的推荐入口类）与 Service Managed Agent 这一串名字、分不清谁是谁时，本篇就是你的起手三步：先认识，再动手，后建图。第 1 章从客服问答、多步骤任务等真实场景出发，说明 AgentScope 能构建什么，以及 Harness 支撑 Agent 持续工作的三个维度——长程任务（跨多步推理、可中断续做的任务）、上下文（Context，一次模型调用能看见的全部输入）与受控执行（工具操作受权限规则约束）。第 2 章动手跑通第一个 HarnessAgent，覆盖依赖安装、共享 Builder（构造器，集中保存 Agent 配置）、`call`（同步等待最终回复）与 `streamEvents`（边执行边输出事件流）两种调用方式，以及跨实例的会话恢复（凭同一会话身份接着对话）。第 3 章把全书概念收拢成一张地图，讲清这三层能力的叠加关系。

本篇适合所有读者：无论后续目标是把 SDK 嵌入自己的 Java 应用，还是在 Service 平台上运营托管 Agent，都建议从这里读起。已有智能体框架经验的读者，也可以先只读第 3 章的概念地图，再按需跳转到感兴趣的章节。

读完本篇，应用开发方向的读者进入第二篇（第 4-10 章）逐一拆解核心构建块，或直接跳到第 11 章理解 Harness 全貌；平台方向的读者可在第 3 章之后进入第五篇（第 29 章起），但建议先完成第 2 章的动手实践。
