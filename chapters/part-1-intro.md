title: 第一篇 起步
source: 新写
---

本篇是全书的起点，用三章完成从“认识”到“动手”再到“建立地图”的第一圈循环：第 1 章从客服问答、多步骤任务等真实场景出发，说明 AgentScope 能构建什么、Harness 围绕长程任务、上下文与受控执行三个维度如何支撑 Agent 持续工作；第 2 章动手跑通第一个 HarnessAgent，覆盖依赖安装、共享 Builder、`call` 与 `streamEvents`，以及跨实例的会话恢复；第 3 章把全书概念收拢成一张地图，讲清 ReActAgent、HarnessAgent 与 Service Managed Agent 三层能力的叠加关系。

本篇适合所有读者：无论后续目标是把 SDK 嵌入自己的 Java 应用，还是在 Service 平台上运营托管 Agent，都建议从这里读起。已有智能体框架经验的读者，也可以先只读第 3 章的概念地图，再按需跳转到感兴趣的章节。

读完本篇，应用开发方向的读者进入第二篇（第 4-10 章）逐一拆解核心构建块，或直接跳到第 11 章理解 Harness 全貌；平台方向的读者可在第 3 章之后进入第五篇（第 29 章起），但建议先完成第 2 章的动手实践。
